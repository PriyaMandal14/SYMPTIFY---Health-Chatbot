# Interactive Health Chatbot – QA Testing

A quality assurance project focused on testing an **interactive health-related chatbot** to ensure accurate, reliable, and consistent responses.

The project involved functional testing of chatbot interactions, validation of health-related output suggestions, and API testing to verify the reliability of backend communication.

---

## Project Overview

The primary objective of this project was to evaluate the chatbot's response accuracy and overall functionality.

Testing was performed to identify incorrect responses, unexpected behavior, and issues in the communication between the chatbot and its backend APIs.

---

## Testing Responsibilities

### 1. Chatbot Response Testing

* Collaborated with developers to test interactive chatbot responses.
* Verified chatbot responses for **accuracy and reliability**.
* Tested different user inputs and chatbot interactions.
* Identified unexpected or incorrect responses during testing.

### 2. Functional Testing

* Conducted functional testing of **health-related output suggestions**.
* Verified that the chatbot provided appropriate responses based on user inputs.
* Tested different scenarios to ensure consistent chatbot behavior.
* Reported issues identified during functional testing.

### 3. API Testing

* Participated in API testing to verify backend communication.
* Tested API requests and responses.
* Verified that chatbot data was correctly exchanged between the frontend and backend.
* Checked API behavior under different input conditions.
